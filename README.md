# 🖥️ Student Walker – Backend

This is the **backend API** for the Student Walker application — a short-distance delivery (jastip) platform where walkers (service providers) fulfill requests simply by walking. The backend handles user management, delivery requests, real-time communication via WebSocket, and file uploads.

> 🗓️ Project started in **December 2024**  
> ⚙️ Current progress: **70%**

## 🧰 Tech Stack

- **Node.js + Express** – RESTful API
- **WebSocket** – Real-time communication
- **Multer** – File uploads
- **MySQL** – Database integration
- **CORS, dotenv, etc.** – Common Express middlewares
